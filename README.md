ResumeBuilder

Why I made this:
The Simplify extension is heavy. I wanted something very light on my computer.

This is not a finished product or too helpful yet, I am still testing and fixing things.

How to run and use:

1. Install dependencies:
pip install -r requirements.txt

2. Start the local backend:
python3 server.py

3. Load the extension:
Open chrome://extensions in Chrome.
Turn on Developer mode.
Click Load unpacked and select the extension folder.

4. Set up your profile:
Open http://localhost:8000 in your browser to enter your address, skills, and work experience.

5. Auto-apply:
Go to a job posting (Workday, Ashby, Greenhouse) and click the Auto-Apply button in the extension.
