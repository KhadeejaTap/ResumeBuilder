HTTP / requests
	HTTP = protocol for client↔server communication over web
	requests lib = python tool to make HTTP calls
	Method: GET = fetch data, POST = send data
	URL = destination endpoint
	Headers = metadata (auth token, content type) — not the actual payload
	Body/json = actual data sent (dict → auto JSON)
	Response = server's reply, .json() parses it to python dict
	raise_for_status() = throws error if request failed (4xx/5xx codes)
